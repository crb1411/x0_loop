0 · 全景概览

EDM2 是 ImageNet-512 / ImageNet-64 类条件 latent 扩散。img512 在 SD-VAE 的 8 通道 64×64 latent 上训练； img64 直接在 RGB 上训练。整条链路按 训练图像数 nimg（而非 epoch/step）计量。

1 · 与原版 EDM(Karras 2022)的关键区别

EDM2 沿用 EDM 的 preconditioning + Heun 采样 + σ-lognormal，新增的全是「训练动力学」层面的工程， 目标是让各层激活/权重幅度在训练全程保持恒定。

方面EDM (2022)EDM2 (2024)
数据空间像素 (CIFAR/FFHQ 64)VAE latent (ImageNet-512) / 像素 (img64)
网络DDPM++/NCSN++,GroupNorm幅度保持 UNet：MPConv/mp_silu/mp_sum/mp_cat，无 GroupNorm
权重普通强制权重归一化（每步把权重投回单位范数）+ 前向再归一
归一化GroupNormpixel norm（沿通道）+ 各 add 用幅度保持系数
可学习增益—out_gain / emb_gain 初始化为 0，让网络从恒等启动
EMA固定 halflifepost-hoc EMA：训练后任意重建 EMA 长度
loss 权重固定 λ(σ)λ(σ) + 学习的不确定性 logvar 自适应再平衡各 σ
guidance无classifier-free + autoguidance（用差版自己引导）

2 · 数据 & VAE latent training/encoders.py

img512 → StabilityVAEEncoder

  • VAE：stabilityai/sd-vae-ft-mse
  • raw latent → 归一：z = z·scale + bias
  • scale = final_std/raw_std，bias = final_mean − raw_mean·scale
  • raw_mean=[5.81,3.25,0.12,−2.15]，raw_std=[4.17,4.62,3.71,3.28]
  • 归一后 latent std ≈ σ_data=0.5，8 通道 64×64

img64 → StandardRGBEncoder

  • 仅把像素缩放到 [−1,+1]（×2−1）
  • 3 通道 64×64，直接像素扩散
  • 采样后 decode 反向回 uint8 像素
类条件：label 是 one-hot，维度 label_dim。--cond=True 时数据集必须带标签。 EDM2 主结果是类条件模型，无条件版另有 -uncond 系列。

3 · 幅度保持网络 UNet / Block / MPConv

核心思想：每个算子都不改变激活的期望幅度，从而无需 GroupNorm 即可稳定训练。

组件作用 (论文式)
MPConv训练时 强制把权重 in-place 投回单位范数(式66)；前向再 normalize 并按 1/√fan_in 缩放(式47)
mp_silusilu(x)/0.596，补偿 SiLU 的幅度衰减(式81)
mp_sum(a,b,t)lerp(a,b,t)/√((1−t)²+t²)，残差/注意力合并保持幅度(式88)
mp_catskip 拼接的幅度保持版(式103)
MPFourier幅度保持傅里叶时间嵌入(式75)；c_noise = ln(σ)/4 作为输入
pixel normencoder 块对输入沿通道维 normalize(x,dim=1)
emb_gain / out_gain初值 0；条件调制 c = emb_linear(emb)·gain + 1，输出 out_conv(x, gain=out_gain)
注意力QK 先 pixel-norm 再 softmax；attn_resolutions=[16,8]
clip_act每个 Block 输出 clip 到 ±256 防溢出

结构：UNet base channels = model_channels × [1,2,3,4]，每分辨率 num_blocks=3， res_balance=attn_balance=0.3，concat_balance=label_balance=0.5。 输入会拼一个全 1 通道（类似 condition-augmentation 占位）。fp16 跑主干，preconditioning 用 fp32。

4 · Preconditioning Precond.forward

网络真正学的是残差 F，去噪输出 D 由跨噪声尺度自动归一的系数组合而成（这正是你 x0_loop 想借的核心）。

c_skip = σ_data² / (σ² + σ_data²)
c_out = σ·σ_data / √(σ² + σ_data²)
c_in = 1 / √(σ_data² + σ²)
c_noise = ln(σ) / 4

F = UNet( c_in · x̃, c_noise, label )
D(x̃, σ) = c_skip · x̃ + c_out · F

这保证无论 σ 多大，网络输入 c_in·x̃ 与回归目标都是单位方差，small/big σ 都不会数值失衡。 σ_data=0.5（latent 已归一到此）。

5 · EDM2Loss + 不确定性加权 training_loop.EDM2Loss

class EDM2Loss(P_mean=-0.4, P_std=1.0, sigma_data=0.5):
  def __call__(net, images, labels):
    rnd   = randn([B,1,1,1])
    sigma = (rnd * P_std + P_mean).exp()           # lognormal σ
    weight = (sigma**2 + sd**2) / (sigma*sd)**2     # EDM λ(σ)，使各 σ 有效权重均衡
    noise  = randn_like(images) * sigma
    denoised, logvar = net(images+noise, sigma, labels, return_logvar=True)
    loss = (weight / logvar.exp()) * (denoised - images)**2 + logvar
    return loss
不确定性再加权（式 21）：网络额外用一个小分支从 c_noise 预测每个 σ 的 logvar=u(σ)。loss 把难（高方差）的 σ 自动降权 1/e^{logvar}，再加 +logvar 防止塌缩。 等价于让各噪声尺度对总梯度的贡献自适应均衡——EDM2 涨点的关键之一。

注意：EDM2 直接回归 x0（denoised vs images），σ 加权 + preconditioning 已把它等价折算到各空间。无显式 v/eps 选择。

7 · 训练主循环 training/training_loop.py

没有 epoch 概念，用 InfiniteSampler 无限取数，按 cur_nimg 推进到 total_nimg。

while cur_nimg < stop_at_nimg:
    # 周期性任务（按 nimg）
    report_status   每 128Ki img → stats.jsonl
    save_snapshot   每 8Mi img   → network-snapshot-*.pkl（每条 EMA 一份, fp16）
    save_checkpoint 每 128Mi img → training-state-*.pt（含 optimizer/ema 全态）

    optimizer.zero_grad()
    for round in range(num_accumulation_rounds):     # 梯度累积凑够 batch=2048
        images, labels = next(iterator)
        images = encoder.encode_latents(images)        # VAE 编码
        loss = loss_fn(net=ddp, images, labels)
        loss.sum().mul(loss_scaling / batch_gpu_total).backward()

    lr = learning_rate_schedule(cur_nimg, batch_size)  # 见 §8
    if force_finite:                                   # 无梯度裁剪！只清 NaN/Inf
        nan_to_num(param.grad, 0, 0, 0)
    optimizer.step()
    cur_nimg += batch_size
    ema.update(cur_nimg, batch_size)

8 · LR / 优化器 / 不裁剪梯度

LR schedule（inverse-sqrt 衰减 + rampup）

lr = ref_lr / √(max(nimg/(ref_batches·B), 1))
× min(nimg/(rampup_Mimg·1e6), 1)

rampup 默认 10 Mimg；ref_batches=decay（img512=70k, img64=35k）；ref_lr 按模型 0.0065–0.017。 无 warmup-cosine、无 min_lr，纯 1/√t 衰减。

优化器 & 稳定性

  • Adam(betas=(0.9, 0.99))
  • 无 weight decay（权重归一化已约束尺度）
  • 无 grad clip — 只 nan_to_num 清掉 NaN/Inf 梯度
  • loss_scaling 缓解 fp16 下溢
与 x0_loop 的明显差异：EDM2 不裁剪梯度、不用 weight decay、不用 cosine。 它靠「强制权重归一化 + 幅度保持层 + 0 初始增益」从结构上稳住训练，而非靠裁剪/wd 这类外部约束。

9 · Post-hoc EMA training/phema.py · reconstruct_phema.py

EDM2 发现「EMA 长度」是强超参，但每个长度重训成本太高。方案：训练时只跟踪 2 条 power-function EMA （stds=[0.050, 0.100]），训练后用线性组合 重建任意目标 EMA 长度。

β(std) = (1 − Δt/t)^(exp(std)+1)  # 随 nimg 自适应，非固定 decay
p_ema ← lerp(p_ema, p_net, 1−β)
  • PowerFunctionEMA：power-function 响应核，无固定半衰期，等价于「相对 std」参数化
  • reconstruct_phema.py：用 solve_posthoc_coefficients（最小二乘）从训练存的 snapshot 解出目标 EMA
  • 预训练权重文件名里的 …-0.130.pkl 那个数字 = 重建出的 EMA 相对 std，专门为最小化 FID/FD_DINOv2 而选
这正是为何同一模型有 -fid 与 -dino 两个 preset：同一份训练，只是重建了不同的 EMA 长度 分别最小化两个指标。EMA 长度 + guidance 是评测期联合调的两个旋钮。

11 · 采样器：EDM Heun 2 阶确定性 generate_images.edm_sampler

FID 用的就是这个采样器，默认参数即评测配置。

# σ 网格：ρ=7 非均匀，从大到小
t_i = ( σ_max^(1/ρ) + i/(N−1)·(σ_min^(1/ρ) − σ_max^(1/ρ)) )^ρ ,  t_N = 0
σ_max=80, σ_min=0.002, ρ=7, N = num_steps = 32 
x = noise · t_0
for i, (t_cur, t_next) in steps:
    d_cur = (x − denoise(x, t_cur)) / t_cur          # 一阶导（Euler 预测）
    x_next = x + (t_next − t_cur) · d_cur
    if i < N−1:                                       # 2 阶 Heun 校正
        d_prime = (x_next − denoise(x_next, t_next)) / t_next
        x_next = x + (t_next − t_cur) · (0.5·d_cur + 0.5·d_prime)
    x = x_next
  • 32 步 → 约 63 次网络前向（NFE）：每步 2 次去噪，最后一步省一次
  • 默认 确定性：S_churn=0（无随机扰动注入），FID 评测即用此
  • denoise 内部直接调 Precond 的 D(x,σ,label)；guidance≠1 时见 §12
  • 每张图固定 seed（StackedRandomGenerator 逐样本独立 generator）→ 可复现

12 · Guidance / Autoguidance denoise()

D_guided(x,σ) = lerp( D_ref(x,σ), D_main(x,σ), w )  = D_ref + w·(D_main − D_ref)
模式gnet（引导网络）典型 w
无 guidancegnet=net（w=1，直接返回 D）1.0
classifier-free（-guid-）同结构的无条件小模型（xs-uncond）1.2–1.9
autoguidance（-autog-）同模型的差版本（更小/欠训的 ckpt）1.7–2.9
Autoguidance（NeurIPS 2024）是 EDM2 仓的另一篇：用「自己的一个更弱版本」当 D_ref 引导， 比传统 CFG 更能压低 FID（img512-xxl autog FID 1.25，img64-s autog FID 1.01）。 注意 guidance 强度 w 是评测期旋钮，与 EMA 长度一起在固定模型上扫优。

13 · 计算 FID 的完整推理方式 ★

这是你特别要的部分。EDM2 计 FID 有两条等价路径：先存图再算，或边生成边算（gen 子命令，不落盘）。

A. 生成 50000 张
generate_images.py · seeds=0–49999 · EDM Heun 32步 · (可选)guidance
B. VAE 解码
latent → encoder.decode → uint8 RGB（img512 才有这步）
C. 特征提取
InceptionV3(2048-d) 和/或 DINOv2 ViT-L/14(1024-d)
D. 累计高斯统计
分布式累加 Σμ、Σσ → 生成集 (mu, sigma)
E. 对参考统计算 Fréchet 距离
ref = dataset-refs/img512.pkl（预存的真实数据统计）

命令（评测期标准配方）

# 直接对模型边生成边算（不存图），8 卡，50000 张
torchrun --standalone --nproc_per_node=8 calculate_metrics.py gen \
    --net=…/edm2-img512-s-2147483-0.130.pkl \      # 选好 EMA 长度的 ema 权重
    --ref=…/edm2/dataset-refs/img512.pkl \          # 真实数据参考统计
    --metrics=fid --num=50000 --seed=0

# 或：先生成 50000 张落盘，再算
torchrun --nproc_per_node=8 generate_images.py \
    --preset=edm2-img512-xxl-guid-fid --outdir=out --subdirs --seeds=0-49999
python calculate_metrics.py calc --images=out --ref=…/img512.pkl --num=50000
采样默认值（即 FID 用值）
  • num_steps=32, σ_min=0.002, σ_max=80, ρ=7
  • S_churn=0（确定性）
  • num_images=50000，max_batch=32/卡
  • label 随机均匀（类条件）
  • net 用的是 snapshot 里的 ema（fp16）
preset 内置的 EMA + guidance
  • -fid：选最小化 FID 的 EMA std（如 0.130）
  • -dino：选最小化 FD_DINOv2 的 EMA std（如 0.190）
  • -guid-/-autog-：额外带 gnet + guidance 强度

14 · FID / FD_DINOv2 数学定义 calculate_metrics.py

特征提取器

  • fid：InceptionV3（StyleGAN3 移植版 pkl），2048 维，输入 uint8 NCHW
  • fd_dinov2：DINOv2 dinov2_vitl14，1024 维；先 bicubic resize 到 224、再按 ImageNet 均值方差标准化

统计累计（分布式）

μ = Σf / N
Σ = (Σ fᵀf − N·μμᵀ) / (N−1)

all_reduce 跨卡求和，最后一个 batch 输出最终 (μ, Σ)。

Fréchet 距离（FID 与 FD_DINOv2 同一公式，只是特征不同）

d² = ‖μ_gen − μ_ref‖² + Tr( Σ_gen + Σ_ref − 2·(Σ_gen Σ_ref)^{1/2} )

矩阵平方根用 scipy.linalg.sqrtm。ref 是预先用 calculate_metrics.py ref 在整个真实数据集上算好的 (μ,Σ)，存成 dataset-refs/*.pkl。生成集只需算自己的 (μ,Σ) 再代入。

与 x0_loop 的口径差异：你用 torch_fidelity + cifar10-train 作 ref，输出 FID/KID/IS/PRC； EDM2 自带 InceptionV3/DINOv2 两套，50000 张、对全数据集 ref、确定性 Heun 63 NFE——比你的 5000/20000 张、20–50 步更「足量」。 跨框架 FID 数值不能直接对比，需统一 ref 与采样预算。
