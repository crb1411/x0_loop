训练核心理念是 把生成语义层层解耦：backbone 只实现 f_θ(x_t, t, cond)， 其余（时间采样、加噪、目标参数化、loss 聚合、CFG、采样、GAN）全部由 Denoiser 包裹层 + Process + Loss 负责。

1 · 四层解耦设计

整个训练目标拆成四个互不偷逻辑的层 —— process 负责物理/几何一致性， target converter 负责参数化一致性，loss 负责实验目标，time_sampler 负责 t 分布。

TimeSchedule core/schedules.py

t 的采样空间、α(t)、σ(t)、snr(t)。diffusion 与 flow 仅在这里通过 α/σ 几何区分。

BaseProcess core/process_base.py

x_t = α(t)x0 + σ(t)eps 的加噪、采样 step，以及 eps/x0/v 三向互转。

OutputTarget process.output_target

模型直接输出哪一种：eps / x0 / v。它只决定 out 的语义，不决定 loss 在哪算。

LossConfig losses/spec.py

在哪些预测空间算 loss + 如何按 t 加权。可在 eps/x0/v 任意空间组合监督。
loss_t = w_outer(t) · Σ_i ( c_i · w_i(t) · L_i(pred_i, target_i) )

关键约束：不要在 model 内部处理 DDPM/Flow 差异；不要在 process 内写死 loss；不要让 output_target 决定 loss_space； 不要把 t_idx=1..1000 泄漏进 loss；不要把 w(t) 藏进 target converter。

CFG label dropout

class_dropout_prob=0.1 时，把 10% 样本标签替换为 null 类 id（=num_classes）， 使模型同时学到条件与无条件分布，供采样期 classifier-free guidance 使用。

4 · 时间采样 t core/time_sampling.py

训练时 t ∈ (0,1] 由 time_sampler.sample(B) 产生（与 schedule 解耦）。所有采样器最终 clamp 到合法区间。

name采样公式用途 / 特性
legacy / schedulediffusion: t=randint(1,N)/N；flow: U(0,1)schedule 驱动的旧默认
uniform_continuoust = min_t + (max_t−min_t)·U(0,1)flow matching 主推；均匀
uniform_discretet = randint(min,max)/num_steps离散步训练
logit_normalz~N(μ,σ); t=sigmoid(z)μ=0,σ=1 集中中段；当前最强基线用
betat~Beta(α,β)→[min,max]α,β<1 偏端点；>1 偏中段

Flow solver-grid 混合 MixedTimeSampler

仅 flow 可用。每个样本独立地：以 1−p 概率走 base 采样器，以 p=grid_mix_prob 概率从「采样器网格时间」取样， 让训练 t 分布对齐推理时实际会落到的离散时刻。

grid_steps=[50,20] → { 1/50, 2/50, …, 1 } ∪ { 1/20, 2/20, …, 1 }  (默认不含 t=0)

5 · 时间条件 jitter denoiser.training_time_condition

训练期可对「喂给模型的条件时间」加扰动，但物理时间 fb.t 保持不变。这是关键的双时间设计。

δ = N(μ, σ)
t_model = clamp(t + δ, min_t, max_t)   # prob<1 时按概率逐样本启用
严格边界（见 gan_…_design.md §2）：物理时间 fb.t 必须用于 forward_sample、target 转换、loss 权重、t-bin 指标、GAN 的 real/fake 配对与 D 条件时间； jitter 后的 t_model 只能进 backbone 前向，绝不参与 target conversion / loss weighting / GAN pairing。
time_condition_jitter:
  enabled: true
  prob: 1.0      # 逐样本启用概率
  mean: 0.0
  std: 0.05
  min_t: 1.0e-5
  max_t: 0.99999

6 · 前向过程 & schedule

统一写成 x_t = α(t)·x0 + σ(t)·eps，diffusion 与 flow 只是 α/σ 几何不同。

Flow（线性插值）

α(t) = 1 − t
σ(t) = t
α + σ = 1
sampler：euler / heun。t=1 高斯端，t=0 数据端。

Diffusion（VP-SDE）

∫β = β_min·t + ½(β_max−β_min)t²
α(t) = exp(−½∫β)
σ(t) = √(1−α²)
α²+σ²=1。sampler：ddim / posterior。
snr(t) = α(t)² / σ(t)²  # 供 loss 权重 snr/inv_snr/logsnr/min_snr 使用

flow forward_sample：抽 eps~N(0,I) → x_t = (1−t)x0 + t·eps，返回 ForwardBatch(x0,t,xt,eps)。

7 · 目标参数化 & 互转 process_base.py

模型直接输出 output_target ∈ {eps,x0,v}，训练侧统一用下面三个函数从同一个 out 还原任意空间， 因此 loss 空间与输出空间完全解耦。

还原out=x0out=epsout=v
x0̂out(x_t − σ·out)/α(x_t − σ·out)/(α+σ)
epŝ(x_t − α·out)/σout(x_t + α·out)/(α+σ)
v̂v = epŝ − x0̂（当 out=v 时直接返回 out）

对应 target：x0_target = x0，eps_target = eps，v_target = eps − x0。

当前 CIFAR10 主配置：output_target = x0，但 loss 在 v 空间计算 —— 即模型预测干净图 x0，loss 监督由 x0̂、eps 反推出的速度 v̂ 对齐 eps−x0。

8 · Loss 设计 losses/spec.py · atomic.py · weighted.py

inner = Σ_i c_i · w_i(t) · L_i(pred_i, target_i)
loss = w_outer(t) · inner

term 字段

loss:
  outer_weight: target          # 见下表
  outer_weight_power: 1.0
  outer_weight_floor: 0.0
  terms:
    - {target: v, formula: mse, coef: 1.0, weight: none}
  • target：eps / x0 / v
  • formula：mse / l1 / huber（huber 用 delta）
  • weight：per-term t 权重，是 escape hatch，一般留 none，优先用 outer_weight

outer_weight 选项

namew(t)（均值归一化后）直觉
none1无加权基线
x0floor+(1−floor)(1−t)^p，如 p=2 → 3(1−t)²重 t→0（干净端）
epsbase=t重 t→1（噪声端）
vbase=1−|2t−1|，p=1 → 2(1−|2t−1|)三角，重中段 t=0.5
target单 term 时取该 term 对应的 x0/eps/v 多项式；多 term 退化为 1自动匹配主目标
snr / inv_snr / logsnrsnr(t) / 1/snr / log snrschedule 诱导
min_snrmin(snr,γ)/snr，min_snr_gamma压高 SNR 区，常用 eps/diffusion
balance_weights(1−bf)+bf·α(t)·mean(1/α)α 平衡，balance_factor

多项式权重默认对 uniform t 做均值归一（均值≈1）。weight_power/weight_floor 缺省回退到 outer_weight_power/floor。

当前主基线 loss：outer_weight=target, power=1.0, floor=0.0，单 term {v, mse, 1.0} → 实际权重是「重中段的三角」乘 v 空间 MSE。

9 · GAN 对抗训练 losses/adversarial.py · models/discriminator.py

目标：模型已从 x_t 预测出 x0̂ 后，用轻量判别器把 x0̂ 拉回自然图像流形 —— 增强而非替代回归目标。 GAN 不并入 CompositeLoss，因为它需要独立 D、detach、独立 optimizer、独立 checkpoint。

9.1 判别器结构 X0Discriminator

输入
x_candidate [B,3,32,32], t [B], cond [B] 可选
stem
SN-Conv3×3 3→16
4× ResDiscBlock
16→32↓ → 32→64↓ → 64→128↓ → 128→128 · LeakyReLU0.2 · 每块 (h+skip)/√2
head
LeakyReLU → 空间求和池化 [B,128] → Linear→标量 logit
投影条件
logit += ⟨h, time_proj(t_embed)⟩/√C + ⟨h, class_embed(y)⟩/√C
  • 全程 spectral_norm，无 BatchNorm，无 FiLM（避免 D 过强）
  • 条件用 projection 方式（time + class embedding）
  • base_channels=16 约 0.4–0.5M 参数

9.2 判别空间

real: D(x0, t, cond)   fake: D(x0̂, t, cond)

real 也喂同一 batch 的 t（x0 本身与 t 无关），避免条件判别器把 real/fake 条件分布差当捷径。 第一版只判别 clean manifold，不输入 x_t（否则退化成 endpoint-consistency critic，低 t 走捷径）。

9.3 Loss（hinge，默认）

D-step（fake 必须 detach）
L_D_real = relu(1 − D(x0))
L_D_fake = relu(1 + D(x0̂.detach()))
L_D = E_w[L_real+L_fake] + ½γ·int·R1
G-step（冻结 D 参数，保留到 x0̂ 的梯度）
L_G_adv = −D(x0̂)
fwd.loss += λ_adv(step) · E_w[ w(t)·L_G_adv ]

可选 logistic non-saturating：L_D=softplus(−D_real)+softplus(D_fake)，L_G=softplus(−D_fake)。

9.4 R1 梯度惩罚（lazy）

R1 = ‖∇_{x0} D(x0)‖²  # 每 r1_interval=16 步算一次, loss 乘 ½·γ·interval 补偿

9.5 λ_adv 调度

step < start_step → 0
否则 λ = weight · min((step−start+1)/warmup, 1)

默认 start_step=10000, warmup_steps=10000, weight≈0.02，D:G=1:1。

9.6 t-aware 对抗权重 w(t) adversarial.t_weight

核心：t 大时 x_t≈噪声，x0̂ 很难像自然图，让这些样本强训 GAN 会逼模型「从纯噪声硬 hallucinate」，破坏回归。 所以对抗 loss 主要作用在 x0̂ 已有结构的中低 t 区。

piecewise 默认 binsw
[0.00, 0.05)0.25
[0.05, 0.35)1.00
[0.35, 0.65)0.50
[0.65, 1.00]0.05

或 smooth gate：w = (1−t)^p · sigmoid((t−t_min)/τ) · sigmoid((t_max−t)/τ)，可 mean 归一。 D 与 G 共用同一 w(t)（D 过强时可单独降高 t 权重）。

9.7 更新与 detach 顺序 engine.maybe_apply_adversarial

# 每 update_every 步：D-step
for _ in range(d_steps):
    with no_grad: fake_d = x0_from_output(xt, t, out.detach())
    use_r1 = (step % r1_interval == 0)
    real = x0.detach().requires_grad_(use_r1)
    real_logits = D(real, t, cond);  fake_logits = D(fake_d, t, cond)
    per_d, per_real, per_fake = discriminator_loss(...)   # hinge
    d_loss = weighted_mean(per_d, w(t)) (+ R1)
    d_loss.backward();  d_optimizer.step()

# G-step（每步）
set_requires_grad(D, False)
fake_g = x0_from_output(xt, t, out)        # 不 detach
g_adv  = weighted_mean(-D(fake_g, t, cond), w(t))
fwd.loss = fwd.loss + λ_adv(step) · g_adv  # 并入主 backward
set_requires_grad(D, True)

11 · 采样 / CFG flow_process.sample

从 t=1 高斯端积分回 t=0。时间网格 linspace(1,0,steps+1)，dt 为负。

Euler

v = epŝ − x0̂
x ← x + dt·v

Heun（预测-校正）

x_e = x + dt·v(t)
x ← x + dt·½(v(t)+v(x_e,s))

最后一步退回 Euler：在 t=0 评估 x0 模型会触发不稳的 eps 反推。

Classifier-free guidance

out = out_uncond + g·(out_cond − out_uncond)
  • num_classes≤0 → 关闭条件
  • guidance_scale==1.0 → 关闭 CFG（即使有标签）
  • >1.0 → 同时跑 cond 与 null-label uncond 再组合
  • 训练期 sample grid 用 g=1.0；gen_eval 用 g=3.0

13 · t-bin 指标 training/metrics.py

把每个 batch 的 per-sample loss / 权重 / GAN 量按 t 分桶（默认 20 桶）累计，日志窗口结束时输出 summary。 既看整体 loss，也能定位「是哪个 t 区间在恶化」。

idx = bucketize(t, linspace(0,1,bins+1))
每桶累计：count · Σloss · Σweight · Σ(GAN: advw/drl/dfl/dacc/gadv)
