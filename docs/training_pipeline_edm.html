2 · 设计空间的四个正交轴

轴含义cifar10-cond-vp 的选择
Preconditioning网络输入/输出/噪声标签如何缩放EDMPrecond：c_skip/c_out/c_in [B,1,1,1]，c_noise [B]
训练噪声分布训练时 σ 怎么采lognormal(P_mean=−1.2, P_std=1.2)，σ [B,1,1,1]
网络架构backboneDDPM++ SongUNet 55.7M：128 基通道 ×[2,2,2]，attn@16×16
采样ODE 求解器 + 时间离散Heun 2 阶 + ρ=7 网格，18 步、t_steps [19]，确定性
EDM 把 DDPM/VP/VE/iDDPM 统一到 ỹ = y + σ·n + 去噪器 D 的框架里，每轴单独消融。 preconditioning + Heun + lognormal 是三个最关键的涨点。

3 · 数据 & 非泄漏增强 training/augment.py

数据集是 dataset_tool.py 打包的 cifar10-32x32.zip（50000 张训练图 + dataset.json 标签）。 loader 输出 uint8 [B,3,32,32]，训练循环里 /127.5−1 转 fp32 [−1,1]。

AugmentPipe（p=0.12）

  • 输入 y [B,3,32,32] → 输出同 shape + aug_label [B,9]
  • 几何：x/y-flip、各向同/异性缩放、分数旋转/平移（启用项：xflip,yflip,scale,rotate_frac,aniso,translate_frac）
  • 每张图独立采样变换参数，9 个标量拼成条件向量

条件注入（防泄漏）

  • map_augment: Linear(9→128, bias=False)，把 [B,9] 投到噪声嵌入 [B,128] 相加
  • 网络「知道」图被增强过 → 增强痕迹不泄漏进生成分布
  • 采样时 aug_label 置 None（等效全 0）→ 生成干净分布
对照 x0_loop：你只有 hflip。这套带条件注入的几何+色彩增强是 CIFAR10 小数据集压 FID 的关键之一——可以放心开激进增强而不污染分布。

4 · DDPM++ SongUNet 逐层 shape ★ training/networks.py · 55.7M 参数

cifar10-cond-vp 的 backbone 配置（train.py --arch=ddpmpp 注入）： model_channels=128, channel_mult=[2,2,2], num_blocks=4, attn_resolutions=[16], embedding_type=positional, channel_mult_noise=1, resample_filter=[1,1], dropout=0.13。 三个分辨率级：32×32 / 16×16 / 8×8，主通道宽度统一为 128×2 = 256。

4.1 条件嵌入（Mapping）

c_noise = ln(σ)/4            # [B,1,1,1].flatten() → [B]
emb = PositionalEmbedding(128)(c_noise)        # [B] → [B,128]，swap sin/cos
emb += Linear(10→128)(label · √10)             # 类条件 [B,10] → [B,128]
emb += Linear(9→128, no bias)(aug_label)       # 增强条件 [B,9] → [B,128]
emb = silu(Linear(128→512)(emb))               # [B,512]
emb = silu(Linear(512→512)(emb))               # [B,512] → 喂给每个 UNetBlock

5 · Preconditioning（统一 4 套）★ EDMPrecond.forward

所有去噪器统一写成 D(x,σ) = c_skip·x + c_out·F(c_in·x, c_noise)。主线用 EDM 列；shape 全程不变。

系数（shape）VPVEiDDPMEDM（主线）
c_skip [B,1,1,1]111σd²/(σ²+σd²)
c_out [B,1,1,1]−σσ−σσ·σd/√(σ²+σd²)
c_in [B,1,1,1]1/√(σ²+1)11/√(σ²+1)1/√(σ²+σd²)
c_noise [B](M−1)·σ⁻¹(σ)ln(σ)/2M−1−idx(σ)ln(σ)/4
# EDMPrecond.forward —— 主线 shape 注释
x      # [B,3,32,32]  加噪图 ỹ
sigma  # [B] → reshape [B,1,1,1]
c_skip = sd²/(σ²+sd²);  c_out = σ·sd/√(σ²+sd²)      # [B,1,1,1]
c_in   = 1/√(sd²+σ²);   c_noise = ln(σ)/4 .flatten() # [B,1,1,1] / [B]
F_x = SongUNet(c_in·x, c_noise, label[B,10], aug[B,9])  # [B,3,32,32]
D_x = c_skip·x + c_out·F_x                               # [B,3,32,32]，σd=0.5
为何 EDM 系数最优：它让网络输入 c_in·x 与回归目标在所有 σ 下都是单位方差， 且 σ→0 时 D≈恒等（c_skip→1）、σ→∞ 时全靠网络（c_skip→0）——数值尺度全程稳定。这正是 x0_loop 现在缺的那块。

6 · Loss & σ 采样 training/loss.py · EDMLoss

class EDMLoss(P_mean=-1.2, P_std=1.2, sigma_data=0.5):
  def __call__(net, images, labels, augment_pipe):
    rnd   = randn([B,1,1,1])                          # [64,1,1,1]
    sigma = (rnd·1.2 − 1.2).exp()                     # [64,1,1,1] lognormal
    weight = (σ²+sd²)/(σ·sd)²                         # [64,1,1,1] = λ(σ)
    y, aug = augment_pipe(images)                     # [64,3,32,32], [64,9]
    n = randn_like(y)·sigma                           # [64,3,32,32]
    D_yn = net(y+n, sigma, labels, augment_labels=aug)# [64,3,32,32]
    loss = weight · (D_yn − y)²                       # [64,3,32,32] 逐像素
    return loss   # 训练循环里 loss.sum()·(ls/64).backward()
Lossσ 采样weight λ(σ)
EDMLoss（主线）lognormal: ln σ~N(−1.2,1.2)(σ²+σd²)/(σσd)²
VPLossuniform t∈[ε,1] 经 VP σ(t)1/σ²
VELosslog-uniform σ∈[0.02,100]1/σ²
EDM 的 lognormal σ = 你 x0_loop logit_normal 时间采样的 σ-空间版本；λ(σ) = 你 outer_weight 的「正确」形式。 loss 是逐像素 [B,3,32,32] 张量，sum 后除以 batch_gpu_total=64 再 backward。

7 · 训练主循环 training/training_loop.py

按 kimg（千张训练图）计量，InfiniteSampler 无限取数，到 total_kimg=200000（200 Mimg）停。 全局 batch 512 = 64/卡 × 8 卡 × 1 轮累积（单卡跑则 num_accumulation_rounds=8）。

while True:
    optimizer.zero_grad()
    for round in range(num_accumulation_rounds):     # 8卡时 =1
        images, labels = next(iterator)                  # [64,3,32,32] uint8, [64,10]
        images = images/127.5 − 1                        # fp32 [−1,1]
        loss = loss_fn(net=ddp, images, labels, augment_pipe)  # [64,3,32,32]
        loss.sum().mul(loss_scaling / 64).backward()

    lr = 1e-3 · min(cur_nimg / 10e6, 1)                  # 线性 rampup 10 Mimg
    nan_to_num(grad, 0, +1e5, −1e5)                      # 无裁剪，只清 NaN/Inf
    optimizer.step()

    # EMA（55.7M 参数逐个 lerp）
    halflife = min(0.5 Mimg, cur_nimg · 0.05)            # rampup
    beta = 0.5 ** (512 / halflife)
    p_ema.lerp_(p_net, 1−beta)
    cur_nimg += 512

    每 tick(50 kimg): 状态行 → stats.jsonl
    每 snap(50 tick = 2.5 Mimg): network-snapshot-*.pkl（ema/loss_fn/augment_pipe）
    每 dump(500 tick): training-state-*.pt（net+optimizer，可 resume）

8 · LR / 优化器 / EMA（主线值）

优化器

Adam(betas=[0.9,0.999], eps=1e-8)
lr=1e-3，无 weight decay

LR schedule

只有线性 rampup（10 Mimg ≈ 19.5k 步），之后恒定，无 decay/cosine

梯度

无裁剪，仅 nan_to_num（NaN→0, ±Inf→±1e5）

EMA

halflife 0.5 Mimg（≈977 步），rampup_ratio=0.05；采样/FID 全用 ema

batch / 时长

512 全局 / 64 每卡；200 Mimg ≈ 390625 步（8×V100 约 2 天）

精度

CIFAR10 默认 fp32（--fp16 可选）；关 TF32
和 x0_loop 的差异：EDM 不裁剪梯度、不用 weight decay、不用 cosine。 靠 preconditioning 把各 σ 数值尺度拉平来稳训练，而非外部约束。

10 · EDM 采样器：Heun 2 阶确定性 ★ generate.py · edm_sampler

FID 用的就是这个。CIFAR10 默认 18 步，每步 2 次去噪、最后一步省 1 次 → 35 次网络评估（NFE）。 生成 batch 默认 64，全程 fp64 积分。

# ρ=7 非均匀 σ 网格，从大到小；t_steps shape = [19]（18 步 + 末尾 0）
t_i = ( 80^(1/7) + i/17·(0.002^(1/7) − 80^(1/7)) )^7 ,  t_18 = 0
σ_max=80, σ_min=0.002, ρ=7, N=num_steps=18 
latents = randn([64,3,32,32])                # 每张图独立 seed（StackedRandomGenerator）
labels  = eye(10)[randint(10,[64])]          # [64,10] 随机类（或 --class 固定）
x = latents.to(fp64) · t_0                   # [64,3,32,32]，t_0=80
for i, (t_cur, t_next) in zip(t_steps[:-1], t_steps[1:]):   # 18 轮
    # 可选 churn（FID 默认 S_churn=0，纯确定性，x_hat=x, t_hat=t_cur）
    denoised = net(x_hat, t_hat, labels)     # D: [64,3,32,32]，内部 fp32
    d_cur  = (x_hat − denoised) / t_hat      # [64,3,32,32] 一阶导
    x_next = x_hat + (t_next − t_hat)·d_cur
    if i < 17:                               # 2 阶 Heun 校正（再一次 D 前向）
        denoised = net(x_next, t_next, labels)
        d_prime  = (x_next − denoised) / t_next
        x_next   = x_hat + (t_next − t_hat)·(0.5·d_cur + 0.5·d_prime)
    x = x_next
# 输出 [64,3,32,32] fp64 → (x·127.5+128).clip(0,255) → uint8 [64,32,32,3] → PNG
  • 确定性：CIFAR10/FFHQ 用 S_churn=0；ImageNet-64 用少量 churn 增稳
  • 每张图固定 seed → 完全可复现；50000 张 = 782 个 batch（64/批）
  • aug_label 不喂（=None）→ 生成未增强分布

11 · Ablation 采样器（全设计空间）ablation_sampler

一个超集采样器，把论文所有采样变体参数化（shape 流与主线相同，仅 σ 网格/调度不同），用来复现「从 DDPM/VP/VE 逐步改造到 EDM」的消融。

旋钮取值
solvereuler（1 阶）/ heun（2 阶）
discretizationvp / ve / iddpm / edm（σ 网格怎么排）
schedulevp / ve / linear（σ(t) 形状）
scalingvp / none（信号缩放 s(t)）

EDM 最优组合 = solver=heun, disc=edm, schedule=linear, scaling=none，即 edm_sampler。 传任一 ablation 参数时 generate.py 自动切到此采样器。

12 · 计算 FID 的完整推理方式 ★ fid.py

两步：先 generate.py 生成 50000 张，再 fid.py calc 对参考统计算 FID。每个箭头标 shape。

A. 生成 50000 张
seeds=0-49999 · 每批 latents [64,3,32,32] · Heun 18 步(35 NFE) · ema 权重 → 50000×PNG(32×32 RGB)
B. InceptionV3 特征
uint8 [n,3,32,32] → feat [n,2048]（StyleGAN3 移植 inception pkl，内部自适应 resize）
C. 累计高斯统计
分布式累加 Σf, Σffᵀ → μ [2048], Σ [2048,2048]（fp64）
D. Fréchet 距离
vs cifar10-32x32.npz（全 50000 张训练集的 μ[2048], Σ[2048,2048]）

命令（评测标准配方）

# 1) 生成 50000 张（可多卡）
torchrun --standalone --nproc_per_node=8 generate.py --outdir=fid-tmp --subdirs \
    --seeds=0-49999 --batch=64 \
    --network=…/edm-cifar10-32x32-cond-vp.pkl

# 2) 对参考统计算 FID
torchrun --standalone --nproc_per_node=1 fid.py calc --images=fid-tmp \
    --ref=…/edm/fid-refs/cifar10-32x32.npz

# 参考统计自己造（一次性，对全训练集）
python fid.py ref --data=datasets/cifar10-32x32.zip --dest=fid-refs/cifar10-32x32.npz

Fréchet 距离定义（2048 维高斯）

FID = ‖μ_gen − μ_ref‖² + Tr( Σ_gen + Σ_ref − 2·(Σ_gen·Σ_ref)^{1/2} )  # μ:[2048], Σ:[2048,2048], sqrtm 用 scipy
口径要点（论文强调）：
  • 固定 50000 张：少于会报错，多了取随机子集。图数对 FID 数值高度敏感。
  • FID 随 seed 波动：论文对每个模型 跑 3 次不同 seed（0-49999 / 50000-99999 / 100000-149999），取最小值。
  • 参考统计 .npz = 在全 CIFAR10 训练集（50000 张）上算的 InceptionV3 (μ,Σ)。
与 x0_loop 口径对比：你用 torch_fidelity + cifar10-train、5000/20000 张、20–50 步、g=3.0，输出 FID/KID/IS/PRC。 EDM 用自带 InceptionV3、固定 50000 张、Heun 35 NFE、确定性、取 3 次最小。要和文献 1.79 可比，必须对齐：图数 50000 + 同一 ref + 多步确定性采样。
